# The d-51 listening kit: how it was built

**2026-09-25. Branch `side/d51-int-level-listen`, NOT for landing** until the owner rules card d-51 (M24
parcel 4, the Z80 `/INT` as a one-line level; design `docs/2026-09-13-z80-timing-currency-design.md` §7 row 4,
sources §6.2). The kit itself lives outside every repo, at `~/sonic_hacks/listen/d51/`; its `README.txt` is
the owner-facing half. This file records how to rebuild it.

## Builds

Each side in its own tree and its own target directory, `CARGO_BUILD_JOBS=4`, offline:

```sh
git worktree add --detach <before-tree> f2cc850          # AFTER: the branch worktree at 508eec4
cd <tree>                && CARGO_TARGET_DIR=<tgt>     cargo build --release --offline -p oracle-player
cd <tree>/tools/listen-kit && CARGO_TARGET_DIR=<tgt>-kit cargo build --release --offline
cp <tgt>/release/oracle-player <tgt>-kit/release/listen-kit ~/sonic_hacks/listen/d51/<before|after>/
```

`tools/listen-kit` is its own workspace root (the `oracle-panels-spike` precedent), so no landing gate builds
it and `z80-census` is switched on only there. Do not build it in-tree without `CARGO_TARGET_DIR`: a
`tools/listen-kit/target/.rustc_info.json` states the compiler's version and reddens `toolchain_floor`.

## Results (measured twice, identical both times)

Census: per `/INT` assert, taken inside one line, taken late, or missed (`crates/oracle-core/src/z80_census.rs`).

| Stretch | Frames | BEFORE taken / late / missed | AFTER taken / late / missed | Lost | WAV diff |
|---|---|---|---|---|---|
| live debug ROM, no input | 1800 | 1798 / 47 / 2 | 1751 / 0 / 49 | 47 | identical, silent |
| fixture ROM, no input (design leg A) | 1200 | 1198 / 33 / 2 | 1161 / 0 / 39 | 37 | identical, silent |
| `ojz` replay | 1900 | 1898 / 45 / 2 | 1851 / 0 / 49 | 47 | differ 21.79-24 s (the only sound) |
| `slide` replay | 2700 | 2698 / 68 / 2 | 2627 / 0 / 73 | 71 | identical, silent |
| sound test | 1800 | 1701 / 167 / 99 | 1534 / 0 / 266 | 167 | differ from 0.4159 s; diff RMS -12.2 dB |
| `ojz` stream on the live ROM | 1900 | 1898 / 47 (12 masked) / 2 | 1848 / 0 / 52 (12 masked) | 50 | identical, silent |

- **Against the design's figures.** Leg A: the design's section 6.1 says 33 grant-spanned acceptances, and
  33 reproduce as "late". The design's "34 of 1198" as the loss does not: measured, 37 are lost, because once
  the driver misses an interrupt the 68000's grant pattern diverges and 4 asserts that were taken in their
  window BEFORE fall into a grant AFTER. (The kit's first commit message guessed "33 late + 1 still open";
  that guess is wrong and is withdrawn here.) The replays are run to a fixed frame count past their end, so
  they are not the design's windows; restricted to the frames before each stream completes, `slide` loses 59
  (design: 57), `ojz` 47 (design: 46).
- **Every late or missed assert on the fixture ROM and the sound test is grant-spanned.** On the live ROM, 12
  are masked (interrupts off for the whole line), which is the half of R6 its author marked unconfirmed.
- **Replay verdicts unchanged**: both still set `Replay_Done` at the same frame (1824, 2449) with the same
  `Logic_Tick` (1798, 2599).
- **Where the misses fall**: in every aeon run, bursts of about 12 consecutive frames roughly every 7.6 s
  (about 3, 10, 18, 26, 33, 41 s from power-on); in the sound test, spread throughout, densest at the same
  instants.
- **Differ controls**: a file against itself reads identical; a copy with one sample moved by one step at
  sample 441000 is reported at exactly that sample, 5.0000 s. Silence (RMS below -60 dBFS) is reported per
  second, so "identical" on a silent render is labelled as such rather than read as "sounds the same".
