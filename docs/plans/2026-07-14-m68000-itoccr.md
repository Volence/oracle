## Goal & scope

Add the three immediate-to-CCR logic instructions, all SST-gated, all reuse on the proven micro-op framework —
the **byte/CCR-form twins** of the shipped `*ItoSR` trio (E6, `to_sr_recipe`):
- **ANDItoCCR** `0x023C` — `CCR &= imm` (clears CCR bits).
- **ORItoCCR**  `0x003C` — `CCR |= imm` (sets CCR bits).
- **EORItoCCR** `0x0A3C` — `CCR ^= imm` (toggles CCR bits).

Each = the sole encoding in its file, **8065 cases**, 100% PURE / 100% in scope (no memory operand → no odd-EA
faults, no exceptions, no corrupt entries, no deferral). +3×8065 over the 946083 baseline → final threshold
**970278**.

**NOT privileged** (unlike `*ItoSR`; the CCR form is legal in user mode). But every vendored case starts
SUPERVISOR anyway, so this is invisible — like every other family, user/supervisor split is unexercised. Do
NOT add a privilege trap (there is none for these ops); do NOT gate anything on privilege.

## Recon findings (exhaustive, 0-mismatch across all 24,195 cases)

- **SR formula:** `new_sr = (sr & 0xFF00) | ((sr op imm) & 0x1F)` — the SR **system byte (bits 8-15) is
  PRESERVED**, only the CCR low-5 bits change; `imm = prefetch[1]`. (Equivalently mask the immediate to the
  CCR bits; the system-byte bits of the immediate are don't-care because the result's high byte comes from the
  original SR.) Verified 0-mismatch for all three ops over every case.
- **CCR ops NEVER change S** → there is NO mid-instruction FC switch (the one way these differ structurally
  from `*ItoSR`, where an AND/EOR clearing S flips the two re-prefetches to FC2). Both re-prefetch reads always
  run under the live supervisor mode's **FC6**.
- Registers unchanged (d0-7/a0-6/usp/ssp); `pc += 4`; prefetch refills from `ram@pc+4` / `ram@pc+6`; ram
  unchanged.
- **length 20** each. Bus stream is IDENTICAL to `to_sr_recipe` (0-mismatch, all cases):
  `[r@pc+4 FC6 .w (leading discard), n8 idle, r@pc+4 FC6 .w (re-prefetch), r@pc+6 FC6 .w (re-prefetch)]`.
  The double prefetch is the full pipe flush; the discard read re-reads the word already in the queue head.

## Vocabulary additions (minimal — one micro-op, one recipe)

- **`MicroOp::CcrLogic { op: LogicOp, value: Operand }`** — the CCR-masking twin of the existing
  `MicroOp::SrLogic`: `regs.sr = (regs.sr & 0xFF00) | (((regs.sr op resolve(value)) & 0x1F))`. 0-cycle,
  non-bus. (`SrLogic` masks the whole SR to `0xA71F` and can clear S; `CcrLogic` touches only the CCR byte and
  can never change S/T/I.) Reuses `LogicOp::{And,Or,Eor}` (already defined for `SrLogic`).
- **`to_ccr_recipe(op: LogicOp)`** — `to_sr_recipe` VERBATIM but pushes `CcrLogic` instead of `SrLogic`:
  `[Read@PcPlus(4) FC=Program .w → TO_SR_DISCARD_SLOT, Internal(8), CcrLogic{op, ImmWord}, Prefetch, Prefetch]`.
  Because CCR never changes S, the two trailing prefetches stay FC6 automatically (the recipe's `Prefetch`
  already uses the live mode). Reuse `TO_SR_DISCARD_SLOT` (the discard read is identical).
- Reuse everything else: `Operand::ImmWord`, `RecipeBuf`, the two drivers, the SST harness.
  `MAX_OPS`/`SCRATCH_SLOTS` unchanged (5 ops).

## Clean vs deferred — the `covered()` strategy

Add `to_ccr_covered(opcode: u16) -> bool` mirroring `to_sr_covered`:
`matches!(opcode, 0x023C | 0x003C | 0x0A3C)`. Wire it into `covered()` next to the `to_sr_covered` arm.
All three files are 100% PURE / in scope (8065 each) — **NO deferral, NO parity filter, NO `(A7)` carve-out**
(there is no memory operand at all). Raise `ran >=` in the runner per commit.

**Decode guard:** the opcodes are `0x023C`/`0x003C`/`0x0A3C` — high nibble 0, low byte `0x3C` (mode 7 reg 4
= the `#imm`-to-condition-code encoding). The `*ItoSR` twins are `0x027C`/`0x007C`/`0x0A7C` (low byte `0x7C`),
so a plain `match` on the full 16-bit opcode disambiguates cleanly. Confirm these don't collide with any
existing line-0 decode arm (ORI/ANDI/EORI to EA, the bit ops, MOVEP): the `0x3C` low byte = mode 7 / reg 4
(`#imm` addressing, illegal as a normal ALU destination) is unique to the to-CCR forms — a full-word match is
unambiguous. Match BEFORE any `& 0xFFC0`-style ORI/ANDI/EORI-to-EA arm so the CCR forms win.
