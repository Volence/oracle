**Status: PLANNED 2026-07-15.** The final Push-A slice: the autovectored interrupt exception and the
STOP-wake path, joining the interrupt arm to the `begin_next` priority dispatch A3.1 built. No SST data
covers this cluster (audit finding 3); recon pinned from `docs/reference/` (Yacht L1549 + M68000UM

## Recon — PINNED from `docs/reference/` (M68000UM §6.3.2 + Yacht L1549 + Table 6-2)

### Trigger, masking, detection (M68000UM §6.3.2, PDF p.96, verbatim-pinned)
- **3-bit priority mask** (SR I2–I0 = `0x0700`): *"interrupts are inhibited for all priority levels less
  than or equal to the current priority."* → an interrupt is TAKEN iff **level > mask** (strict); level
  ≤ mask is **postponed** (held pending), not lost.
- **Detected between instructions**: *"Pending interrupts are detected between instruction executions."*
  → a `begin_next` boundary event, exactly like trace.
- **Level 7 = NMI**: *"cannot be inhibited by the mask"*; generated on the **edge** *"each time the
  interrupt request level changes from some lower level to level 7"*, and also by the level comparison if
  request = 7 and priority was lowered by an instruction. (Mega Drive rarely uses 7; the edge semantics
  → **docket**, the level-comparison path is the A4.1 core.)

### Exception processing (§6.3.2, PDF p.96-97)
- **SR copy saved** (the OLD SR, before the mask change) — stacked.
- **S set, T cleared** ("tracing is suppressed") — the existing `EnterException`.
- **NEW: processor priority ← the interrupt level** (*"the processor priority level is set to the level
  of the interrupt being acknowledged"*). `EnterException` does NOT touch the mask (no other exception
  changes it), so A4 adds a `SetIntMask { level }` micro-op AFTER `EnterException` (which captured the
  OLD SR first, so the stacked SR is pre-mask — correct).
- **IACK cycle** acquires the vector; **autovector** (Mega Drive VPA): *"the processor internally
  generates a vector number corresponding to the interrupt level."* Vector = **24 + level** (Table 6-2:
  L4→28/`0x70`, L5→29, L6→30/`0x78`, L7→31/`0x7C`). VBLANK = L6 → vector 30; HBLANK = L4 → vector 28.
- **Stacked PC = the next instruction** (*"the address of the instruction that would have been executed
  had the interrupt not been taken"*) — same as trace; the live `pc` at the boundary.
- **Frame** = the standard 6-byte SR+PC frame.

### Timing + bus stream (Yacht L1549)
Interrupt = **44(5/3)**, `n nn ns ni n- n nS ns nV nv np n np`. The three stack writes are **`s S s`**
(PCL, then — after the `ni` IACK cycle — PCH, SR): **same final order as the trace frame** (`push_trace_frame`),
BUT the IACK (`ni`) cycle interleaves *between the PCL write and the PCH/SR writes*, so the interrupt
recipe is not a verbatim `push_trace_frame` reuse. Reads (5): `ni` IACK + `nV nv` vector + `np np`
reload. Writes (3): the frame. The exact interleave placement of `ni`/`n-` idles is a **timing** detail —
pin from Yacht (it is explicit) or, if the stream doesn't reproduce cleanly, **docket** it.

### Priority (already pinned — §6.2.3 / A3 recon)
`begin_next`: **trace > interrupt > decode**. Trace (pended by the previous instruction) is serviced
first; then a pending interrupt with level > mask; then decode the next instruction. The A3.1 dispatch
already has the `trace_pending` arm — A4 inserts the interrupt arm directly after it.

### STOP wake (§6.3.2 "detected between instructions" + §5.1 stopped state)
A `Stopped` CPU resumes on an interrupt whose **level > mask** (or reset). On wake it services that
interrupt; the frame's stacked PC = the instruction after STOP (the wake first advances past the 2-word
STOP + refills the queue — the A1 `stop_recipe` wake note). **A T=0 STOP woken by a plain interrupt is
FULLY PINNED and independent of A3.2's T-fork** — keep it separate; do not let the STOP×trace open cell
block the wake.

## Design

### New vocabulary
- `Cpu68000::set_ipl(level: u8)` + a serialized `ipl: u8` latch (the external request level; 0 = none).
  The System (Push C) will drive it; A4 tests set it directly.
- `MicroOp::SetIntMask { level }` — set SR I2–I0 = `level` (after `EnterException` captured the old SR).
- `registers.rs`: `SR_INT_MASK = 0x0700` + `Registers::int_mask()` / mask helpers.
- `decode.rs` (or a new `interrupt.rs`): `interrupt_exception_recipe(level)` — `[TargetCalc(PcPlus(0)),
  EnterException, SetIntMask(level), <IACK cycle>, push (s S s, IACK-interleaved), vector_fetch_and_reload(
  (24+level)*4)]`. NOT marked `suppresses_trace` (interrupts aren't a decode result).
- `MicroOp::IntAck { level }` (or reuse a Read with a distinct FC) — the `ni` IACK cycle so the bus stream
  shows it; autovector generates the vector internally (no external vector read).

### `begin_next` dispatch (extends A3.1)
```
if self.trace_pending { ...service trace... }          // A3.1 (unchanged)
else if self.ipl > self.regs.int_mask() {               // A4: interrupt (strict level > mask)
    let level = self.ipl;
    service interrupt_exception_recipe(level);           // stacks next-instr PC, mask ← level
}
else { ...latch trace, decode+run next instruction... } // A3.1
```
Trace's pended latch is checked first (trace > interrupt). When both a trace and an interrupt are ready on
the same boundary, trace is serviced this `begin_next`, the interrupt the next — the UM sequencing.

### STOP wake (begin_next, `Stopped` state)
When `state == Stopped`: if `ipl > mask` (or reset), clear `Stopped`, run the STOP-wake tail (advance past
the STOP, refill), then fall into the interrupt arm. Otherwise consume idle in slice-sized chunks so
`run_until` (Push C) terminates. (A T=1 STOP's trace-preempts-stop is A3.2 — out of scope here.)

## Slicing
### A4.1 — the autovectored interrupt exception
`set_ipl` + `ipl` latch + `SetIntMask` + `IntAck` + `interrupt_exception_recipe` + the `begin_next`
interrupt arm. Hand vectors (no SST): taken when level > mask / postponed when ≤; mask raised to the level
in the running SR; OLD SR (pre-mask) stacked; stacked PC = next instruction; autovector = 24+level (L4→28,
L6→30); both drivers; **priority** (a pending trace beats a pending interrupt on the same boundary). SST
stays 1,000,058 (off the vendored path).

**Pin the IACK-interleaved `s S s` stream NOW, from Yacht L1549** (owner's call): the line spells it out
explicitly (`ns ni n- n nS ns`) — the same authority and the same kind of claim as the trace `s S s`
order (L1548), pinned without hesitation. The docket is for what the references *cannot* answer;
downgrading an explicit Yacht line to "confirm later" would invert the evidence hierarchy. Build the
interrupt recipe's stream to match Yacht directly, and pin it in a dedicated stream test (PCL write →
IntAck → PCH write → SR write). The plan's escape valve stands: docket the stream *only* on a genuine
failure to reproduce against the harness — then it is a finding, not a guess.

**Level-7 caveat — do NOT enshrine the edge cell** (owner's correction): the A4.1 dispatch is `ipl > mask`
(strict), which *postpones* `ipl=7, mask=7` — but the UM says level 7 "cannot be inhibited by the mask."
That cell is exactly the edge-vs-level semantics in docket entry 3. The strict-comparison *implementation*
is deferred (Mega Drive barely uses L7), which is fine — but **no A4.1 test may assert "ipl=7, mask=7 →
postponed" as pinned behavior**; leave that cell explicitly absent / marked docket-pending, so the harness
slice inherits an honest gap, not a test enshrining the known-wrong answer. The `ipl=7, mask<7` case is
covered by the ordinary comparison and IS asserted freely.

**End-to-end trace > interrupt chain** (owner's addition — cheap once the machinery exists): a T=1
instruction completes with an interrupt pending → the trace services on the FIRST boundary, the interrupt
on the SECOND, and the interrupt handler's first instruction is **not** traced (T was cleared by the trace
exception's own `EnterException`). Closes the loop on the trace>interrupt sequencing end-to-end, rather
than asserting the two halves separately.

### A4.2 — STOP wake — SHIPPED 2026-07-15
`Stopped` CPU + `ipl > mask` → wake, advance past the 2-word STOP (`pc += 4`), service the interrupt
(stacked PC = post-STOP). **The wake reduced to exactly `pc += 4`** — no separate refill/bus activity, since
the interrupt arm's own `vector_fetch_and_reload` refills the queue (the interrupt's 44(5/3) is the only
pinned stream; Yacht has no STOP-wake entry). T=0 path only (T=1 STOP×trace is A3.2). The `begin_next`
`Stopped` arm sits above the trace/interrupt arms; on wake it clears `Stopped`, advances, and falls through
to the interrupt. Tested: wake stacks the post-STOP PC + raises the mask; stays stopped while masked (and
wakes once the mask drops below the pending level); and a **snapshot/restore-across-idle** run wakes
identically to an uninterrupted one (boundary discipline for the one indefinitely-sitting state).
**Deferred (not guessed):** the `STOPPED_IDLE_SLICE` per-poll idle cost (a `run_until` progress device, NOT
pinned — no Yacht STOP-wait entry) and the **reset-wake** arm (shaped-but-unwired until Push B brings a real
reset sequence — no faked reset).

## Anti-cheating / invariants
- SST ground truth, untouched — `step()`/`ipl`/`begin_next` are off the vendored path; gate stays exactly
  1,000,058, re-run before each commit.
- Behavioral facts pinned from `docs/reference/` only; the bus-stream/edge residue is docketed as a
  differential, cross-checked over the bus, never emulator source.
- New serialized fields (`ipl`) round-trip snapshots.

## Risks
- **Mask-copy ordering**: the stacked SR must be the OLD SR — `EnterException` captures it before
  `SetIntMask` runs. Assert the stacked SR carries the pre-interrupt mask, not the new level.
- **IACK-interleaved writes**: the `s S s` frame is split by the IACK cycle — build/test the interrupt
  recipe's stream directly (not by reusing `push_trace_frame` unmodified).
- **trace-vs-interrupt on one boundary**: order is trace-then-interrupt across two `begin_next` calls;
  test that both fire, trace first.
- **STOP-wake / T-fork separation**: keep the T=0 wake independent of A3.2 (do not gate wake on the
  unresolved loaded-SR-T question).
