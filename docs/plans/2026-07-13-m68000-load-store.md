**Opcode-space note (the 0x48xx / 0x4xxx neighbourhood).** EXT/SWAP already decode with a mode-000-only guard
(`0xFFF8`) precisely so the non-mode-0 `0x48xx` space is free for PEA/MOVEM — see the existing runner comments
("would swallow the PEA/MOVEM neighbours in 0x48xx"). New arms must be mode-guarded so they never collide:
- `0x4840` mode 000 = SWAP (already), mode ≥ 2 = PEA. `0x4880` mode 000 = EXT.w (already), mode ≥ 2 = MOVEM.w r→m.
  `0x48C0` mode 000 = EXT.l (already), mode ≥ 2 = MOVEM.w r→m long? No — `0x48C0` = MOVEM.l r→m (bit6=1). Guard
  MOVEM by its full mask `0xFB80` (`opcode & 0xFB80 == 0x4880`) AND a valid mode, so EXT/SWAP (mode 0) never match.
- MOVEM direction = bit 10 (`0x0400`): `0x4880`/`0x48C0` = reg→mem (.w/.l), `0x4C80`/`0x4CC0` = mem→reg (.w/.l).
- EXG (`0xC1xx`) sits in the 0xC space next to MULU/EXG/ABCD; use mask `0xF130 == 0xC100` and switch on the
  opmode field. Modes 000/001 of the AND `Dn,<ea>` space are "ABCD/EXG reserved" (already excluded by
  `is_dst_mem_mode`) — EXG is decoded by its own opmode arm, not the AND arm.

### The six simple ops
- **NOP:** length 4, recipe `[Prefetch]`. Nothing but pc+=2 + queue shift.
- **EXG:** length **6 always** (`[Prefetch, Internal(2)]`). Swap the two registers named by the opmode form. A7
  is the active `addr_reg(7)` (ssp/usp per S). No memory, no flags. (opmode counts: 0x08 → Dx,Dy; 0x09 → Ax,Ay;
  0x11 → Dx,Ay.)
- **LEA:** `An ← EA`, control modes only (2, 5, 6, 7/0 abs.w, 7/1 abs.l, 7/2 d16(PC), 7/3 d8(PC,Xn)). No operand
  read — the address itself is the result. **Timing by mode: (An)=4, d16(An)=8, d8(An,Xn)=12, abs.w=8,
  abs.l=12, d16(PC)=8, d8(PC,Xn)=12.** d16(PC) base = pc+2 (the ext-word address).
- **PEA:** compute EA (same control modes), push it as a long to `-(SP)`. **Timing = LEA + 8** (the two word
  pushes): (An)=12, d16=16, d8Xn=20, abs.w=16, abs.l=20, d16(PC)=16, d8(PC,Xn)=20.
- **LINK:** length **16**. `SP-=4; [SP]=An; An=SP; SP=SP+s16(disp)`. Bus: read disp word, write An.hi @ SP−4,
  write An.lo @ SP−2, prefetch refill. **A7 QUIRK (1005 cases): `LINK A7` pushes SP−4, not the old A7** — the
  predecrement of SP happens FIRST, and since An≡SP the stored value is the already-decremented SP.
- **UNLINK:** length **12**. `SP=An; An=[SP] (long pop); SP=An_old+4`. Bus: 2 word reads (the popped long) +
  prefetch refill.

### MOVEM (the structural op)
Register mask = ext word 1 = `regs.prefetch[1]` — **available at decode time** (like the Bcc/DBcc live reads), so
`decode()` expands it into an exact-length linear recipe. `n = popcount(mask)`. **No flags, ever.**
- **Register ↔ bit mapping:** NORMAL (`bit0=D0 … bit7=D7, bit8=A0 … bit15=A7`) for every case EXCEPT **reg→mem
  `-(An)` predecrement**, where the mask is interpreted **REVERSED** (`bit0=A7, bit1=A6 … bit8=D7 … bit15=D0`).
- **Allowed modes:** reg→mem = {2, 4 (`-(An)`), 5, 6, 7/0, 7/1} (control-alterable + predecrement; NO PC, NO
  `(An)+`). mem→reg = {2, 3 (`(An)+`), 5, 6, 7/0, 7/1, 7/2, 7/3} (control + postincrement + PC-relative).
- **reg→mem control (fwd):** EA computed once; store D0..A7 (set bits, ascending) at increasing addresses.
- **reg→mem `-(An)`:** predecrement the running address by `size` BEFORE each store; iterate the REVERSED order;
  An ends = the final decremented address. **When An is itself in the list, the stored value is the INITIAL An**
  (the model that writes current register values is 0-mismatch — An is not modified until the end; this is the
  68000 behaviour, distinct from the 68020).
- **mem→reg:** load forward from increasing addresses. **`.w` SIGN-EXTENDS each loaded word to the full 32-bit
  register**; `.l` loads a full long. `(An)+`: An ends = `base + n·size` (the phantom read below does NOT advance
  An). PC-relative modes are mem→reg only.
- **THE PHANTOM READ (mem→reg only):** a single trailing **word** read (always word, even for `.l`) at the
  address one word past the last transferred word; its value is discarded. This is the constant **+4** in every
  mem→reg base timing.
- **Timing (0-mismatch, every mode consistent): `length = base + per·n`, per = 4 (`.w`) / 8 (`.l`).**
  - reg→mem base: `(An)`=8, `-(An)`=8, `d16(An)`=12, `d8(An,Xn)`=14, `abs.w`=12, `abs.l`=16.
  - mem→reg base (= reg→mem + 4 phantom): `(An)`=12, `(An)+`=12, `d16(An)`=16, `d8(An,Xn)`=18, `abs.w`=16,
    `abs.l`=20, `d16(PC)`=16, `d8(PC,Xn)`=18.
- **Address errors (odd base → group-0 abort, IN SCOPE via the existing E3/E4 mechanism):** MOVEM faults ONLY
  when the base address is odd — every step is even, so it faults on the FIRST access with nothing transferred:
  ssp−=14, pc→vector-3 handler, register file unchanged, **EXCEPT `(An)+` commits `An += 2` (one WORD step)
  before the abort, for BOTH `.w` and `.l`** (the long access is word-at-a-time; the pointer advances one word,
  then the odd-address fault). This mirrors the E4 "(An)+ auto-increment commits before the faulting read" rule.

## The mechanism

**Reuse (C0–C3):**
1. **EA calc for control modes** (LEA/PEA) — the same `EaCalc`-into-scratch machinery the operand-EA path uses,
   but with the LEA/PEA idle profile (no operand `Read`; the address IS the result). LEA writes the scratch EA
   to `An` (a no-flag `Move`/`AddrReg` write, like `MoveA`); PEA pushes it long via the BSR/JSR push machinery
   (`TargetCalc`/`ScratchHi16`+`Scratch` writes to `-(SP)`). Note LEA/PEA d8(An,Xn)/abs.l carry the standard
   extra idle already visible in the timing table.
2. **The long-push / long-pop machinery** (LINK/UNLINK/PEA) — reuse BSR/JSR's `TargetCalc` (unmasked) →
   `ScratchHi16`/`Scratch` writes to `-(SP)`, and RTS/UNLK's two-`Read`+`Combine32` pop. LINK also needs the
   `An=SP; SP+=disp` register update (a small decode-time-computed adjust — mind the A7 aliasing and the A7
   predecrement-first quirk). EXG is a pure register swap: a new tiny op (see vocab).

**MOVEM (C4–C5) — the decode-time list expansion (the structural change):**
`decode()` reads `mask = regs.prefetch[1]`, computes the ordered register list (reversed for `-(An)`), and emits a
linear recipe: [EA-base calc] → per-transfer ops in order → [phantom word read, mem→reg only] → [trailing
prefetch(es)]. Because the recipe stays a flat linear list, **both drivers + mid-instruction snapshot/restore keep
working unchanged** (exactly like the Bcc/DBcc decode-time expansion). Two representation options for the
impl agent (pick against the per-cycle gate + `MAX_OPS` budget):
- **(A) per-register op** (recommended): one `MicroOp::MovemLoad{reg,size,...}` / `MovemStore{reg,size,...}` per
  register, each doing its 1 (word) or 2 (long) bus accesses internally and logging that many transactions, with
  the running address in a scratch slot and the `+size` step. 16 regs → 16 ops → **`MAX_OPS` ≈ 24** suffices.
  Quiesce granularity = per register (the two words of a long register transfer together — acceptable; the SST
  snapshot anchors still snapshot between registers).
- **(B) per-word op**: one transfer op per WORD accessed. Finer quiesce (per bus access, the stated default
  granularity) but 16 regs `.l` → 32 ops → **`MAX_OPS` ≈ 40**.

Either way: the ascending/reversed order, the sign-extension (mem→reg `.w`), the phantom read, the `(An)+` final
An and the predecrement final An are all baked into the emitted sequence by `decode()`. Odd-base address errors
fall out of the existing E3/E4 abort on the first transfer's Read/Write — with the `(An)+` `An += 2`-before-fault
ordering matching the E4 precedent (ensure the postincrement of the running pointer/An commits its first word
step before the faulting access, so a faulting `(An)+` leaves `An = base + 2`).

## Risks
- **`MAX_OPS` bump (the one structural change).** MOVEM.l 16-register expansion must fit. Size it to the chosen
  representation (≥24 per-register / ≥40 per-word) with headroom; keep `MicroState` a fixed `[MicroOp; MAX_OPS]`
  array (bincode/Copy invariant). Confirm the `RecipeBuf` cap + any `[…; MAX_OPS]` initializers move together.
- **MOVEM `(An)+` address error → An += 2.** The postincrement of the running pointer must commit ONE WORD before
  the faulting access, for both `.w` and `.l` — mirror the E4 "(An)+ commits before the faulting read" ordering.
  Pin the odd-base `(An)+` anchors (`.w` and `.l`) — the `.l` case (An += 2, NOT 4) is the subtle one.
- **MOVEM predecrement store order + the long store word order.** Reversed mask, decrement-before-store; for `.l`
  confirm the two-word store order against the data (like the MOVE.l `-(An)` predecrement reversal). An-in-list
  stores the INITIAL An (68000, not 68020).
- **The phantom read** is a real bus transaction (word, discarded) — the per-cycle gate WILL catch it if missing
  or mis-placed. It does not advance An.
- **LINK A7 aliasing** (An ≡ SP): predecrement SP first, then the stored value is SP−4; An then = SP−4, then
  SP += disp. Pin `0x4E57`.
- **EXG A7** exchanges the active `addr_reg(7)` (ssp/usp per S) — pin `0xc18f`.
- **d16(PC) base = pc+2** for LEA/PEA/MOVEM PC-relative (the ext-word address) — the EaCalc must run before any
  prefetch advances pc (the existing `PcOfExt`/`DispWord` capture-before-refill discipline).
