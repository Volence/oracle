# oracle-next — 68000 status-register moves: MOVEfromSR · MOVEtoCCR · MOVEtoSR · MOVEfromUSP · MOVEtoUSP

Author: session 0a6d861c · 2026-07-14 · branch `m68000-microop-framework` (HEAD `1e41e02`).
Recon: my own exhaustive **0-mismatch** Python over the pinned SST data (`scratchpad/sr-recon/`); see the
`recon-sr-moves` memory. This is the recommended next family after the X-flag arithmetic cluster (the
arith/logic/shift/bit/mul/div/BCD/multi-precision + flow + exception + load/store families are complete).

## Goal & scope

Add the five status-register move instructions, all SST-gated, all reuse on the proven micro-op framework:
- **MOVEfromSR** `0x40C0|ea` — `EA.w = SR` (full 16 bits). Data-alterable dest. NOT flags. NOT privileged (68000).
- **MOVEtoCCR** `0x44C0|ea` — `CCR = (SR & 0xFF00) | (src.w & 0x1F)`. Data source. NOT privileged.
- **MOVEtoSR** `0x46C0|ea` — `SR = src.w & 0xA71F`. Data source. Privileged (unexercised — see below).
- **MOVEfromUSP** `0x4E68|An` — `An = USP`. Privileged (unexercised). Reg-direct.
- **MOVEtoUSP** `0x4E60|An` — `USP = An`. Privileged (unexercised). Reg-direct.

**Privilege is correctness-only / UNEXERCISED.** Every vendored case in all 5 files starts SUPERVISOR (S=1, T=0),
exactly like the T-bit trace and the exceptions-push E6 `*toSR`. Implement the privilege trap minimally or defer
it with a documented caveat (mirror E6 — do NOT gate it, and do NOT add untested trap code that a case can't
validate). No case exercises the user→supervisor privilege-violation entry.

Each file = **8065 cases**, 100% in scope (no corrupt entries, no deferral). +40325 over the 889628 baseline →
final threshold **929953**.

## Recon findings (exhaustive, 0-mismatch)

### MOVEfromUSP / MOVEtoUSP — trivial register moves (S0)
- Both share base `0x4E40`; distinguish by bit 3: `0x4E60|An` = to-USP, `0x4E68|An` = from-USP.
- **MOVEfromUSP**: `An = USP` (full 32). **MOVEtoUSP**: `USP = An`. SR unchanged, no flags. **4 cyc**, ONE
  prefetch transaction. `An==A7` routes through `addr_reg`/`addr_reg_set` (supervisor A7 = SSP) — from-USP A7
  sets SSP=USP, to-USP A7 sets USP=SSP. Reg-direct only → **NO exceptions** (8065 clean each). 0-mismatch.

### MOVEfromSR — SR → EA (S1)
- Value: `EA/Dn.w = SR` (all 16 bits incl the system byte). **NO flags** (SR unchanged).
- **Register (Dn)**: SR→Dn low16, high word preserved. **6 cyc**, bus `rn` = `[Prefetch, Internal(2)]` (write
  is a 0-cycle internal). 
- **Memory**: the **68000 read-before-write quirk** — a dummy word READ of the EA (value discarded) then a
  word WRITE of SR. This is **CLR.w's `ea_dst` RMW shape but writing SR (no flags) instead of 0 (Z=1)**. Odd EA
  → a **READ** address error (the dummy read faults first). Per-mode cyc: (An)/(An)+ 12, -(An) 14, d16(An) 16,
  d8(An,Xn) 18, abs.w 16, abs.l 20 (= standard word RMW `8 + ea`). 5017 clean / 3048 fault. 0-mismatch.

### MOVEtoCCR / MOVEtoSR — EA → CCR/SR (S2, S3)
- **MOVEtoCCR**: `CCR = (SR & 0xFF00) | (src.w & 0x1F)` — system byte preserved, CCR bits 5-7 forced 0. **Reuse
  RTR's `LoadCcr` (mask 0x1F).** S never changes → trailing reads stay FC6. 4958 clean / 3107 fault.
- **MOVEtoSR**: `SR = src.w & 0xA71F`. **Reuse RTE's `LoadSr` (mask 0xA71F).** Mode CAN switch to user (S
  cleared): the trailing flush-read + prefetch then run under the **NEW** mode's FC (FC2 user-program) — verified
  on 2313 switch cases, 0 violations. Same mid-instruction FC switch the E6 `to_sr_recipe` already proved.
  4938 clean / 3127 fault.
- **Both share ONE bus shape** (the one novel shape this push):
  `[ea_src(Word) operand read (with its extension-word refills)] → Internal(4) → LoadSr/LoadCcr(operand) →
  discard Read@PcPlus(2) (the pipe-flush re-read, NEW-mode FC) → Prefetch (NEW-mode FC)`.
  The LoadSr/LoadCcr runs BEFORE the flush-read + prefetch so the MOVEtoSR FC switch applies to both trailing
  reads. **Timing is uniform: `cycles = ea_src_word_read_cost + 12`** (+12 = n4 + flush 4 + prefetch 4):
  reg 12, An/(An)+ 16, -(An) 18, d16/abs.w/d16(PC) 20, d8(An,Xn)/d8(PC,Xn) 22, abs.l 24, #imm 16. 0-mismatch all
  modes. The **#imm** mode is exactly the existing `to_sr_recipe` shape (discard Read@pc+4 + LoadX(ImmWord) + two
  Prefetches, but with `Internal(4)` not ANDItoSR's `Internal(8)`). The double prefetch = full pipe flush; the
  flush-read re-reads the word already in the queue head (an extra bus read vs a normal op's single final prefetch).

### Exceptions — group-0 address error, reuse the E3/E4 abort VERBATIM (0-mismatch)
For MOVEfromSR / MOVEtoCCR / MOVEtoSR odd word EAs: `SSW = (opcode & 0xFFE0) | 0x15` (read | data | fc5);
`IR = opcode`; access-addr = FULL-32 faulting EA; stacked PC = live `regs.pc` (advances +2 per extension-word
prefetch consumed before the fault — d16/d8/abs modes stack pc+2, (An)+/-(An) stack pc+0). All three fault on a
READ (dummy read for MOVEfromSR; operand read for toCCR/toSR). `(A7)`/`(A7)+`/`-(A7)` all IN scope. 0-mismatch on
SSW/IR/addr/PC — the existing abort produces every frame for free.

## Vocabulary additions (kept minimal)
- **`Operand::Sr`** — resolves to `regs.sr as u32` (MOVEfromSR's write value, for both the Dn.w write and the
  memory write).
- A **no-flag word write of `Operand::Sr`** for MOVEfromSR (memory reuses the `ea_dst` RMW read-then-write with
  the read discarded; register is `[write Dn.w=SR, Prefetch, Internal(2)]`). CLR's `Move{Zero}` sets flags — so
  this needs a no-flag path (a dedicated `AluOp`/write that leaves SR untouched, NOT `AluOp::Move`).
- **`MicroOp::MoveUsp { to_usp: bool, an: u8 }`** — 0-cycle, non-bus, A7-aware register↔USP transfer
  (`to_usp ? regs.usp = addr_reg(an) : addr_reg_set(an, regs.usp)`), mirroring `ExgRegs`.
- Reuse: `LoadSr` (MOVEtoSR), `LoadCcr` (MOVEtoCCR), the `ea_src`/`ea_dst`/CLR machinery, the E3/E4 abort. A
  dedicated `move_to_sr_ccr_recipe(opcode, to_sr: bool)` builds the shared toCCR/toSR shape (S2 proves it without
  the FC switch; S3 = same builder + `LoadSr`, FC switch falls out). `MAX_OPS` already 40 (abs.l toSR ≈ 8 ops).

## Clean vs deferred — the `covered()` strategy
Add per-op predicates (mirroring the existing `_covered` twins), each verified exact against every opcode; guard
the EA modes so the neighbours (NEGX `0x4000`, NEG `0x4400`, NOT `0x4600` — all size-field ≠ 3; the `0x4E4x`
line-4 misc) never match:
- **MOVEfromSR** `(op & 0xFFC0) == 0x40C0`, dest mode ∈ {0,2,3,4,5,6} or (mode 7, reg ∈ {0,1}) — data-alterable.
- **MOVEtoCCR** `(op & 0xFFC0) == 0x44C0`, src mode ∈ {0,2,3,4,5,6} or (mode 7, reg ∈ {0,1,2,3,4}) — data + PC-rel + #imm.
- **MOVEtoSR** `(op & 0xFFC0) == 0x46C0`, src modes identical to MOVEtoCCR.
- **MOVEfromUSP** `(op & 0xFFF8) == 0x4E68`. **MOVEtoUSP** `(op & 0xFFF8) == 0x4E60`. (reg = An 0-7, all in scope.)
- **No deferral, no parity filter, no (A7) carve-out.** Odd word EAs are address errors the E3/E4 abort covers;
  `(A7)`/`(A7)+`/`-(A7)` are all in scope. All 5 files are 100% PURE / in scope (8065 each). **Detect exceptions
  by a vector-3 fetch (read @ 0x0C/0x0E, FC5), NOT an "ssp changed" heuristic** — `(A7)+`/`-(A7)` legitimately
  mutate SSP via the addressing mode (this bit me in recon).
- **Raise `ran >=`** in the runner (currently `889_628` at line ~1989) per commit — see the commit plan.

## Risks
- **The toCCR/toSR bus shape** (the pipe-flush re-read + double prefetch). The novel piece — the flush Read@pc+2
  runs under the NEW mode's FC, and the timing `ea_read + 12` includes it. Pin every mode's anchor; the #imm mode
  reduces to the existing `to_sr_recipe` shape (a cross-check).
- **MOVEfromSR read-before-write.** It is a *write* instruction that faults on the *dummy READ* first (SSW read
  bit set). Reusing CLR's `ea_dst` gives this for free — but the write value is SR with NO flags (unlike CLR).
- **Privilege is unexercised** — do not gate a privilege trap; document it as correctness-only (mirror E6 T-bit).
- **`(A7)+`/`-(A7)` mutate SSP legitimately** — not exceptions. Exception detection = vector-3 fetch, never an
  ssp-change heuristic.
- **USP A7 routing** — from/to-USP with An=A7 hits SSP in supervisor mode via `addr_reg`; pin both A7 anchors.
